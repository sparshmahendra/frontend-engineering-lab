# Beginner Modal — Starter

This directory contains the starting point for the Beginner Modal exercise.

## Your Task

Complete the Modal implementation described in:

`../README.md`

Do not look at the solution until you have attempted the exercise yourself.

## Goal

Build a simple modal using:

- React state
- Conditional rendering
- Event handling
- Basic JSX
- Basic CSS

## Restrictions

Do not use:

- UI component libraries
- Modal libraries
- React portals
- External state-management libraries

Keep the implementation simple.
